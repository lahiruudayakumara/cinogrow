🧠 Algorithm Pipeline — v10 Step by Step

# ── STEP 1: Exponential Sample Weights ─────────────── w[t] = λ^(n−1−t) # λ=0.992, w[-1]=1.0 (most recent) # Half-life ≈ 86 weeks · 2017 data weight ≈ 0.015 # All 522 rows used — satisfies ≥500 requirement # ── STEP 2: Holt-Winters Damped Trend Fit ──────────── min Σ w[t]·(y[t] − ŷ[t])² → {α, β, φ} α=0.5016 β=0.1765 φ=0.8000 ŷ_HW[t+h] = L + (Σ_i φ^i)·T (damped trend sum) # ── STEP 3: LightGBM on residuals ε = y − ŷ_HW ──── X_feat = [lag₁‥lag₁₂, rollMean4, rollStd4, rollMean12, rollStd12, price_level, weeks_break] LGBM_mean.fit(X, ε, weights=w) # L2 objective LGBM_qlo.fit(X, ε, weights=w) # τ=0.05 quantile LGBM_qhi.fit(X, ε, weights=w) # τ=0.95 quantile # ── STEP 4: Combined Forecast ───────────────────────── ŷ[t] = ŷ_HW[t] + LGBM_mean.predict(X_feat) PI_lo = ŷ_HW + LGBM_qlo (LGBM native lower) PI_hi = ŷ_HW + LGBM_qhi (LGBM native upper)
# ── STEP 5: Recursive State Update ─────────────────── for t in hold-out: ŷ[t] = ŷ_HW[t] + LGBM_mean(X_feat) # Update HW state with actual observation L_new = α·y[t] + (1−α)·(L + φ·T) T_new = β·(L_new−L) + (1−β)·φ·T # Update LGBM feature buffer ε_new = y[t] − (prev_L + φ·prev_T) buf.push(ε_new) # slide forward # No leakage — each step uses only past observations # ── STEP 6: Conformal Prediction Intervals ──────────── scores = |y − ŷ| (calibration: last 104 weeks) margin = quantile(scores, ⌈(n+1)(1−α)⌉/n) CI_CP = [ŷ ± margin] # P(Y ∈ CI_CP) ≥ 1−α (finite-sample guarantee) # ── STEP 7: Blended Interval ───────────────────────── CI_blend = 0.5·CI_LGBM + 0.5·CI_CP # Combines LGBM adaptivity + CP guarantee # Result: 100% empirical coverage on hold-out ✓ All 4 hold-out weeks inside ALL interval types

📊 Data Context & Structural Regimes

Three Price Regimes

2017–2021 (Low-price era)Rs 2,500–3,800
2022 (Crisis spike, break)Rs 3,800–8,500
2023–2026 (Current)Rs 5,000–5,500
λ=0.992 half-life ≈ 86 weeks assigning downweighted importance to older regimes while preserving all 522 rows for the ≥500 academic requirement.

Why LightGBM over AR?

AR(p) is purely linear — it cannot model:
• Nonlinear momentum (spike vs mean-reversion asymmetry)
• Lag × volatility interactions
• Regime-conditioned patterns

LightGBM builds gradient-boosted trees on 18 residual features, learning nonlinear mappings that AR cannot express. Sample weights ensure consistent λ-treatment with HW.
